# Security

Please report security issues in this plugin or in Restream's MCP server to **developers@restream.io**. Include steps to reproduce and the app you used (for example Claude, ChatGPT, Cursor). We aim to respond within 5 business days. Please don't open a public issue for a vulnerability.

What the plugin does with your data is described in the README under "Data and network".
